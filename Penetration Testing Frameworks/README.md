## Overview

This room explores established penetration testing frameworks and methodologies used to structure security assessments. It covers their objectives, phases, and practical applications in different environments.

## Frameworks Covered

### OSSTMM

The Open Source Security Testing Methodology Manual provides a scientific methodology for security testing. It focuses on operational security and uses Risk Assessment Values (RAVs) to measure security.

### OWASP Web Security Testing Guide (WSTG)

A comprehensive guide for testing web application security. It organizes testing activities into categories and provides a structured approach to identifying vulnerabilities.

### NIST SP 800-115

A technical guide for information security testing and assessment. It provides recommendations for planning, conducting, and analyzing security tests.

### Penetration Testing Execution Standard (PTES)

A framework that organizes penetration testing into seven main phases, from pre-engagement interactions to reporting.

### Information Systems Security Assessment Framework (ISSAF)

A framework for conducting information system security assessments, covering different testing areas and methodologies.

### MITRE ATT&CK

A knowledge base of adversary tactics, techniques, and procedures (TTPs) based on real-world observations. It helps security professionals understand and analyze attacker behavior.

### Other Frameworks

- PCI DSS Penetration Testing Guidelines
- OWASP Mobile Application Security Testing Guide (MASTG)
- Cloud Security Alliance Cloud Controls Matrix (CCM)

## Key Takeaways

- Frameworks provide structure and consistency to penetration tests.
- Different frameworks address different technologies, environments, and compliance requirements.
- Choosing the right framework depends on the assessment scope and objectives.
- Combining multiple frameworks can provide broader security coverage.

## Conclusion

Understanding penetration testing frameworks helps security professionals plan assessments, identify vulnerabilities, validate security controls, and communicate findings effectively.
