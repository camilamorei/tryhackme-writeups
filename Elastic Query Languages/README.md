# Elastic: Query Languages

## Overview

This room explores advanced query techniques in Kibana, focusing on how security analysts can search, filter, and investigate large datasets using different query languages.

The exercises demonstrate how to work with structured and nested data, identify patterns, define search ranges, and investigate security events through advanced queries.

## Objectives

- Understand the query languages available in Kibana.
- Perform searches using different query syntaxes.
- Navigate and investigate nested fields.
- Use regular expressions to identify patterns in event data.
- Apply ranges and boundaries to refine search results.
- Perform fuzzy and proximity searches.
- Investigate security incidents using advanced queries.

## Topics Covered

### Elastic Query Languages

Introduction to the query languages available in Kibana, including their syntax, operators, and practical applications.

### Nested Data

Working with nested fields and understanding how structured event data is organized in Elasticsearch.

### Regular Expressions

Using regular expressions to identify patterns, match variations, and search for specific values within event fields.

### Ranges and Boundaries

Filtering events based on numerical values, dates, and defined boundaries to narrow investigation results.

### Fuzzy and Proximity Searches

Searching for terms with slight variations and identifying words that appear close to each other within event data.

### Security Event Investigation

Applying advanced queries to investigate incidents, identify suspicious activity, and analyze security events.

## Key Takeaways

- KQL is useful for filtering and narrowing down search results in Kibana.
- Lucene provides additional search capabilities, including regular expressions and fuzzy searches.
- Understanding nested fields is essential when investigating structured security data.
- Regular expressions help identify patterns that are difficult to find through exact matching.
- Range queries make it easier to investigate events within specific time periods or severity levels.
- Proximity searches help identify relationships between terms in event messages.
- Elastic Common Schema (ECS) provides a standardized structure for event fields.
- Event Query Language (EQL) supports event correlation and sequence-based detection.

## Conclusion

Completing this room provided practical experience with advanced querying techniques in the Elastic Stack.

These skills are useful for security monitoring, threat hunting, incident investigation, and detection engineering. Being able to construct precise queries helps analysts identify relevant events, reduce noise, and investigate suspicious activity more efficiently.
