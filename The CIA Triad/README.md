## Task 2: Understanding the CIA Triad

### Confidentiality

Confidentiality ensures that sensitive data can only be accessed by authorized individuals.

Example: preventing unauthorized people from accessing credentials or private information.

### Integrity

Integrity ensures that data is not modified by unauthorized individuals.

Example: preventing someone from changing a bank transaction or modifying an exam grade without permission.

### Availability

Availability ensures that data and services are accessible to authorized users when needed.

Example: keeping a company's website available during business hours.

## Task 3: The Security Mindset

The CIA Triad is more than a collection of definitions. It provides a security mindset that can be used to understand the impact of security incidents.

Security professionals can ask questions such as:

* Was sensitive data exposed to unauthorized individuals?
* Was data modified without permission?
* Were systems or services unavailable when needed?
