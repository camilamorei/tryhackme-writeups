# Report Writing for SOC L2

## Overview

This room focuses on the importance of report writing in cybersecurity operations, particularly for Level 2 SOC analysts. It explains how to communicate investigation results, document security incidents, and prepare reports for different audiences.

## Learning Objectives

- Understand the responsibilities of an L2 SOC analyst.
- Learn how to write clear and structured SOC reports.
- Understand the purpose of handover notes.
- Organize investigation findings into an attack timeline.
- Use AI tools to assist with report writing responsibly.

## Topics Covered

- SOC L2 responsibilities
- SOC reporting and communication
- Executive summaries
- Handover notes
- Attack timelines
- Context in AI prompts
- Limitations of generative AI in critical decisions

## Key Takeaways

- L2 analysts help bridge communication between the SOC and external stakeholders.
- Reports summarize investigation findings and communicate relevant information.
- Handover notes are technical documents designed to help other analysts continue an investigation.
- Attack timelines organize events chronologically, making incident analysis easier to understand.
- Providing context improves the quality and relevance of AI-generated reports.
- AI can support report writing, but analysts must review its output and remain responsible for critical decisions.

## Tools and Technologies

- Security Operations Center (SOC)
- Generative AI tools
- Incident investigation and reporting techniques

## Conclusion

This room demonstrates that effective report writing is an essential skill for SOC L2 analysts. Clear documentation, accurate timelines, and proper communication help teams understand incidents, coordinate their response, and make informed security decisions.
