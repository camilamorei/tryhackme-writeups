# Senior Security Analyst Intro

## Overview

This room introduces the progression from a SOC Level 1 analyst to a SOC Level 2 analyst, explaining the responsibilities, technical skills, soft skills, and mindset required for a more advanced role in Security Operations.

It covers the transition from basic alert triage to complex investigations, incident response, detection engineering, and collaboration with other teams.

## Learning Objectives

- Understand the responsibilities of a SOC Level 2 analyst.
- Identify the differences between Level 1 and Level 2 roles.
- Recognize the importance of technical and soft skills.
- Understand the importance of incident handling and threat hunting.
- Develop an attacker mindset to improve investigations.
- Learn about detection engineering and security operations tasks.

## Topics Covered

### SOC Level 2 Responsibilities

- Investigating escalated security alerts.
- Performing advanced log analysis.
- Supporting incident response activities.
- Building and improving detection rules.
- Conducting threat hunting exercises.
- Mentoring junior analysts.
- Communicating with IT and other departments.

### Technical and Soft Skills

Both technical and soft skills are important for becoming a Level 2 analyst.

Technical skills include log analysis, incident investigation, detection engineering, and understanding security tools.

Soft skills include communication, leadership, initiative, responsibility, and mentorship.

### Incident Handling

Level 2 analysts investigate more complex security incidents, including:

- Infostealer infections.
- Supply chain attacks.
- Insider threats.
- Active Directory compromises.
- Malware infections.

Investigations may involve SIEM, EDR, command-line tools, host analysis, network analysis, malware analysis, and OSINT.

### Attacker Mindset

Understanding how attackers operate helps analysts identify attack patterns, anticipate possible next steps, and investigate suspicious activity more effectively.

### Engineering and General Security Tasks

SOC Level 2 analysts may also work on:

- Developing and tuning detection rules.
- Automating repetitive tasks.
- Maintaining SIEM and EDR solutions.
- Improving network security configurations.
- Supporting vulnerability management and compliance activities.

## Key Takeaways

- Becoming a SOC Level 2 analyst requires improving both technical and soft skills.
- Exploring different security domains helps develop broader knowledge.
- An attacker mindset helps analysts understand and predict incident progression.
- Senior analysts must take responsibility for security concerns and ensure critical systems remain monitored.
- The role involves more than alert triage, including engineering, incident response, and collaboration.

## Tools and Technologies

- SIEM
- EDR
- Splunk
- Command-line tools
- MITRE ATT&CK
- Cyber Kill Chain
- OSINT

## Conclusion

Senior Security Analyst Intro provided an overview of the responsibilities and mindset expected from a SOC Level 2 analyst. The room emphasized the importance of technical development, communication, initiative, mentorship, and understanding attacker behavior.

It also highlighted how broader security knowledge and practical experience contribute to professional growth in Security Operations.
